> 目标：把这个项目变成「能拿得出手的上线作品」。写于 2026-10-24，资质政策以当时查证为准，提交前再核对一遍官方文档。

## 〇、先定形态：四条路线对比

| 路线                                       | 成本           | 周期      | 个人可行     | 价值   |
| ---------------------------------------- | ------------ | ------- | -------- | ---- |
| **A. PWA**（网页安装到桌面/主屏）                   | 极低（0 元）      | 1–2 天   | ✅        | ⭐⭐⭐  |
| **B. 微信小程序**（个人主体）                       | 低（免费，可选服务器钱） | 2–4 周   | ✅（有类目限制） | ⭐⭐⭐⭐ |
| **C. 安卓 APK 上应用市场**（华为/小米/OPPO/vivo/应用宝） | 高            | 1–2 个月+ | ❌ 几乎不可行  | ⭐    |
| **D. iOS App Store**                     | 中（$99/年）     | 1 个月+   | ✅（需 Mac） | ⭐⭐   |

**推荐顺序：A → B，C 放弃，D 看兴趣。**

- **C 的三座大山（2026 实测规则）**：① 华为/小米/OPPO/vivo/应用宝**全部强制软件著作权**（申请周期 1–2 个月）；② 要 ICP 备案 + 工信部 **APP 专项备案**双证；③ 主流市场基本只收**企业主体**，个人只能上极简工具且处处受限。为简历项目花 1–2 个月办这些，性价比最低。
- **B 是最贴合「应用市场」认知的路线**：个人身份证就能注册发布，免费，工具类目对个人开放。但有一个**大坑**：AI 助手是「实时 AI 生成内容」，按微信规则可能触发**深度合成类目，个人主体不开放**——上小程序时 AI 功能大概率要砍掉或降级（如只做静态小结模板）。这是决策前必须知道的。
- **A 是纯白送的**：GitHub Pages 已在线，加 manifest + Service Worker 就能「安装」，还能写进简历（离线可用、Lighthouse 指标）。

- [ ] 版本号体系（1.0.0）+ CHANGELOG.md
- [x] 一句话介绍 + 详细介绍文案 + 5 张以上截图（docs/shots 已更新：总览 / 名单 / 考勤 / 战术板 / 成长 / AI 助手 / 主题，2026-10-25）

### 合规 & 法律

- [ ] **隐私政策**页面（收集什么：localStorage 数据 / 邮箱密码 / API Key；不收集什么）——所有路线都要
- [ ] 用户协议（简版即可）
- [ ] 明确「数据归属用户，可随时导出删除」

### 质量保障

- [ ] 至少一轮完整真机测试（手机浏览器 + 平板 + 微信内置浏览器）
- [ ] 错误监控：前端接免费 Sentry（或自建 `/api/log`），至少捕获 window.onerror
- [ ] 单元测试补齐核心纯函数（parseRosterText、normalizeFormation、SSE 解析器）
- [ ] Lighthouse 四项分数截图留档（面试素材）
- [ ] 空状态/断网态/慢网态过一遍

### 安全加固（server/）

- [ ] express-rate-limit（登录/注册接口限流防爆破）
- [ ] helmet 安全头
- [ ] JWT_SECRET 强随机 + 定期轮换说明
- [ ] SQLite 定时备份脚本（cron / 任务计划 + 备份到另一块盘）
- [ ] HTTPS（若公网部署：Caddy 自动证书最省事）

## 三、路线 B：微信小程序（2–4 周）

### 资质与账号

- [ ] 注册个人主体小程序账号（身份证 + 人脸核身，免费，个人名下上限 5 个）
- [ ] 选类目：**工具 → 效率/信息查询**（如实选，别跨类目）
- [ ] **小程序 ICP 备案**（2023-09 起强制，7–20 个工作日，个人可备）
- [ ] 配置《用户隐私保护指引》
- [ ] 若用自建后端：域名必须 HTTPS + ICP 备案 + 小程序后台配 request 合法域名（备案期间可先用云开发绕开）

### 技术改造

- [ ] 选路线：原生 WXML 重写 / uni-app / Taro（已有 Vue 3 基础，**uni-app 最顺**）
- [ ] localStorage → wx.setStorageSync 适配层（数据层逻辑可全复用）
- [ ] 登录体系改 wx.login（云端模式）或纯本地模式（个人主体更稳）
- [ ] **AI 助手决策**：① 砍掉（最稳）② 降级为「本地模板小结」（不调模型，不触深度合成）③ 硬上（大概率被拒，浪费审核周期）
- [ ] 战术板 touch 事件适配（现有 pointer 逻辑基本可复用）
- [ ] 无 canvas 导出依赖检查（阵型导出 PNG 在小程序里要 wx.canvasToTempFilePath）

### 上架流程

- [ ] 开发者工具上传 → 体验版 → 真机预览测试
- [ ] 提审材料：截图、功能说明、测试账号
- [ ] 常见驳回自查：诱导分享 / 类目不符 / 页面空白 / 需要登录才能用（首页必须先见功能）
- [ ] 审核通过 → 发布
